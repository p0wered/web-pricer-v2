# WebPricer v2

Поиск по базе радиодеталей, собираемой из Excel-файла поставщиков.
Решения и план разработки — в [PLAN.md](PLAN.md). Инструкция по развёртыванию для DevOps
появится на этапе 5.

## Структура

| Путь              | Что внутри                                                                        |
| ----------------- | --------------------------------------------------------------------------------- |
| `apps/server`     | API на Fastify; запускается прямо из TS-исходников (нативный type stripping Node) |
| `apps/web`        | SPA на React + Vite + Tailwind                                                    |
| `packages/shared` | Общие для сервера и фронта схемы API (zod) и типы                                 |
| `tools/benchmark` | Скрипты замеров и регрессионный набор запросов                                    |
| `docs`            | Отчёты (замеры скорости и т. п.)                                                  |

## Разработка

Нужен Node.js ≥ 22.18 (в Docker используется Node 24).

```bash
npm install
```

```bash
npm run dev
```

Сервер слушает `http://localhost:3000`, фронт — `http://localhost:5173` (запросы `/api`
проксируются на сервер).

```bash
npm run check
```

`check` запускает проверку форматирования, линтер, проверку типов и тесты.

## Запуск в Docker

```bash
docker compose up -d --build
```

Приложение будет доступно на `http://localhost:9091`.
